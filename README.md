# Entité — Foundry VTT

Système Foundry VTT v14 pour **Entité — Jeu de rôle solo NASA Punk**.

## Périmètre du premier jalon

Le premier jalon couvre les règles de base jusqu’à la page 30 de l’édition française :

- fiche PIA ;
- Traits et Capacités ;
- jets d’Action avec Avantage / Désavantage ;
- réussite totale, réussite partielle et échec ;
- Énergie, Ressources et Données ;
- combinaison spatiale à 20 emplacements ;
- Améliorations, Contraintes et Défaillances ;
- Structures ;
- RollTables du jeu de base ;
- journal de bord lié au PIA.

Les Règles avancées et les Extras sont hors du premier jalon. L’automatisation complète du cycle Mission → Expédition → Exploration → Activité secondaire viendra dans un second temps.

## Principes UX

- Un seul Actor `pia`.
- Pas d’assistant de création dans la première itération.
- Les conséquences d’un jet ne sont pas appliquées silencieusement : le Chat propose des actions explicites.
- Les Améliorations sont déclenchées explicitement ; leur coût et leurs effets peuvent ensuite être automatisés.
- La feuille reprend l’organisation rouge / noir / blanc de la feuille papier et l’étend vers une esthétique NASA-punk.

## Compatibilité

Foundry VTT v14.
